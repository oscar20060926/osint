# Scripts de instalación

- `setup-debian.sh` — instalación sobre Trace Labs / Debian 13 (apt).
- `setup-blackarch.sh` — instalación de tools BlackArch (pacman/blackman).
- `hardening.sh` — endurecimiento y OPSEC.
- `backup.sh` — backup cifrado de la bóveda y configs.

> No incluir credenciales ni datos reales en los scripts.
