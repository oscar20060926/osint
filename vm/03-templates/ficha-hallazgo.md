# Ficha de Hallazgo

## Resumen
Un hallazgo = una nota. Duplica esta plantilla por cada entidad (persona, usuario, dominio, imagen).

## Contenido

- **Tipo de entidad:** persona / usuario / dominio / imagen / email / teléfono / IP
- **Identificador:** (handle, dominio, email…)
- **Fuente:** URL o herramienta que lo aportó
- **Fecha de captura:** YYYY-MM-DD
- **Evidencia:** enlace a Wayback/archive, hash (Hunchly), captura
- **Nivel de confianza:** alta / media / baja
- **Estado:** #fp/pendiente · #fp/confirmado · #fp/descartado
- **Fuentes corroborantes:** (2+ independientes para confirmar)
- **Notas:** contradicciones, soft-404, falsos positivos descartados
